# אפיון – עוזר אישי בטלגרם

## 1. מטרה
בוט טלגרם אישי שמתפקד כעוזר יומיומי: מנהל תזכורות ומשימות, שומר פתקים, עוקב אחרי
הוצאות פשוטות, ומשוחח בצ'אט חכם (AI) לכל שאלה שלא תואמת פקודה מוכרת.

הבוט מיועד לשימוש אישי (משתמש יחיד או כמה משתמשים, כל אחד עם הנתונים שלו לפי chat id).

## 2. טכנולוגיה
- **Node.js** (v18+) + **Telegraf** – ספריית הבוטים.
- **node-cron** – בדיקת תזכורות שהגיע זמנן, פעם בדקה.
- **@anthropic-ai/sdk** – מנוע ה-AI לצ'אט החכם (Claude). ניתן להחליף בקלות לספק אחר.
- **אחסון**: קובץ JSON מקומי (`data/db.json`) – בסיס נתונים פר-משתמש, בלי צורך
  בשרת DB חיצוני. פשוט לפריסה ולגיבוי (קובץ אחד).
- **dotenv** – ניהול משתני סביבה (טוקנים).

## 3. יכולות (Features)

### 3.1 תזכורות ומשימות (To-Do)
- `/task <טקסט>` – הוספת משימה לרשימה (בלי תאריך).
- `/tasks` – הצגת כל המשימות הפתוחות, ממוספרות.
- `/done <מספר>` – סימון משימה כבוצעה (מוחקת מהרשימה).
- `/remind <YYYY-MM-DD HH:MM> <טקסט>` – תזכורת לזמן מוחלט.
- `/remind in <Nm|Nh|Nd> <טקסט>` – תזכורת יחסית (לדוגמה `/remind in 30m להתקשר לרופא`).
- `/reminders` – רשימת תזכורות ממתינות.
- `/cancel <מספר>` – ביטול תזכורת.
- כל דקה הבוט בודק תזכורות שהגיע זמנן ושולח הודעה יזומה למשתמש.

### 3.2 פתקים (Notes)
- `/note <טקסט>` – שמירת פתק חדש.
- `/notes` – הצגת כל הפתקים, ממוספרים.
- `/delnote <מספר>` – מחיקת פתק.

### 3.3 ניהול הוצאות פשוט
- `/expense <סכום> <קטגוריה> [תיאור]` – רישום הוצאה, לדוגמה `/expense 45 אוכל פיצה`.
- `/expenses [today|week|month|all]` – סיכום הוצאות לפי תקופה (ברירת מחדל: החודש הנוכחי),
  כולל פירוט לפי קטגוריה וסה"כ.
- `/delexpense <מספר>` – מחיקת רשומת הוצאה.

### 3.4 צ'אט חכם (AI)
- כל הודעת טקסט חופשית שאינה פקודה מוכרת נשלחת ל-Claude ומוחזרת תשובה.
- נשמר הקשר שיחה קצר (כמה הודעות אחרונות) פר-משתמש כדי לאפשר שיחה זורמת.
- `/reset` – איפוס הקשר השיחה.
- אם לא הוגדר מפתח API, הבוט מודיע למשתמש שהתכונה לא מוגדרת, במקום לקרוס.

### 3.5 כללי
- `/start` – הודעת פתיחה + הסבר קצר.
- `/help` – רשימת כל הפקודות.
- כל הנתונים מבודדים לפי chat id (משתמש רואה רק את הנתונים שלו).

## 4. מבנה נתונים (`data/db.json`)
```json
{
  "users": {
    "<chatId>": {
      "tasks": [{ "id": 1, "text": "...", "createdAt": "..." }],
      "notes": [{ "id": 1, "text": "...", "createdAt": "..." }],
      "expenses": [{ "id": 1, "amount": 45, "category": "אוכל", "desc": "פיצה", "date": "..." }],
      "reminders": [{ "id": 1, "text": "...", "dueAt": "ISO date", "sent": false }],
      "aiHistory": [{ "role": "user|assistant", "content": "..." }]
    }
  },
  "nextId": { "task": 2, "note": 2, "expense": 2, "reminder": 2 }
}
```

## 5. מבנה קוד
```
telegram-assistant/
  package.json
  .env.example
  README.md
  src/
    bot.js            – נקודת כניסה, רישום handlers, launch
    db.js             – קריאה/כתיבה ל-db.json + helper functions
    scheduler.js       – cron שבודק תזכורות שהגיע זמנן
    handlers/
      tasks.js
      notes.js
      expenses.js
      ai.js
    utils/
      parseTime.js     – פענוח "in 30m" / "YYYY-MM-DD HH:MM"
```

## 6. הרצה ופריסה
1. יצירת בוט ב-BotFather בטלגרם וקבלת טוקן.
2. `cp .env.example .env` והזנת `TELEGRAM_BOT_TOKEN` (וגם `ANTHROPIC_API_KEY` אם רוצים AI).
3. `npm install`
4. `npm start`
5. לפריסה תמידית: כל שירות שמריץ Node לאורך זמן (Render / Railway / VPS + pm2 וכו').

## 7. הרחבות עתידיות (לא בסקופ הראשוני)
- תזכורות חוזרות (יומי/שבועי).
- גרפים/ייצוא CSV להוצאות.
- ריבוי שפות אוטומטי לפי שפת המשתמש בטלגרם.
- אינטגרציה עם יומן Google.
