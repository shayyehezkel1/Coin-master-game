# תזכורות

אפליקציית תזכורות פשוטה בנויה עם React, TypeScript ו-Vite.

## יכולות

- הוספה, השלמה ומחיקה של תזכורות
- קטגוריות מובנות + הוספת קטגוריות מותאמות אישית
- תזכורות חוזרות (יומי / שבועי / חודשי) — עם השלמה, המועד מתקדם אוטומטית לחזרה הבאה
- התראות דפדפן (Notification API) לתזכורות שהגיע זמנן
- שמירה מקומית ב-localStorage, ללא צורך בשרת

## הרצה

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```
